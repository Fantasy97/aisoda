# 抽牌游戏 API 接口文档

## 项目概述

抽牌游戏是一个基于Node.js + Express + Socket.IO的多人在线卡牌游戏，支持4人实时对战，包含地主竞拍和农民抽牌两个核心玩法。

## 技术栈

-**后端**: Node.js + Express.js

-**实时通信**: Socket.IO

-**前端**: HTML5 + CSS3 + JavaScript

## 服务器信息

-**基础URL**: `http://localhost:3000`

-**Socket.IO端点**: `ws://localhost:3000`

---

## REST API 接口

### 1. 游戏管理接口

#### 1.1 初始化游戏

```http

POST /api/init-game

Content-Type: application/json


{

  "playerNames": ["玩家A", "玩家B", "玩家C", "玩家D"]

}

```

**响应**:

```json

{

  "success": true,

  "gameState":{

    "gameState":"bidding",

    "players":[...],

    "biddingInfo":{...},

    "deckInfo":{...}

  }

}

```

#### 1.2 重置游戏

```http

POST /api/reset-game

Content-Type: application/json

```

**响应**:

```json

{

  "success": true,

  "gameState":{...}

}

```

#### 1.3 获取游戏状态

```http

GET /api/game-state

```

**响应**:

```json

{

      "handValue":50,

      "entryFee":100,

      "finalScore": null

    }

  ],

  "biddingInfo":{

    "currentBid":20,

    "currentBidder":"玩家B",

    "biddingRound":1,

    "biddingTurnCount":2

  },

  "totalPool":420,

    "totalCards":25,

    "flippedCards":3,
```

## Socket.IO 事件

### 客户端监听事件

#### 1. gameStateUpdate

游戏状态更新事件，包含完整的游戏状态信息。

```javascript

socket.on('gameStateUpdate', (gameState) => {

  // 处理游戏状态更新

  console.log('游戏状态:', gameState.gameState);

  console.log('当前回合:', gameState.gameRound);

});

```

#### 2. cardsDrawn

玩家抽牌事件

```javascript

socket.on('cardsDrawn', (data) => {

  // data: { playerId, cards }

  console.log(`${data.playerId} 抽取了 ${data.cards.length} 张牌`);

});

```

#### 3. cardsFlipped

玩家翻牌事件

```javascript

socket.on('cardsFlipped', (data) => {

  // data: { playerId, results, triggeredBomb }

  console.log('翻牌结果:', data.results);

  if (data.triggeredBomb) {

    console.log('触发炸弹!');

  }

});

```

#### 4. playerLeft

玩家离场事件

```javascript

socket.on('playerLeft', (data) => {

  // data: { playerId }

  console.log(`${data.playerId} 离开了游戏`);

});

```

### 客户端连接事件

#### connection

客户端连接时触发

```javascript

io.on('connection', (socket) => {

  console.log('客户端已连接:', socket.id);

  

  // 发送当前游戏状态

  socket.emit('gameStateUpdate', gameEngine.getGameState());

  

  socket.on('disconnect', () => {

    console.log('客户端已断开:', socket.id);

  });

});

```

## 数据模型

### 游戏状态模型

```typescript

interface GameState {

  gameState: 'waiting' | 'bidding' | 'playing' | 'finished';

  gameRound: number;

  roundPhase: 'draw' | 'flip' | 'decide';

  currentPlayerIndex: number;

  playersDrawnThisRound: string[];

  playersActedThisRound: string[];

  players: Player[];

  biddingInfo: BiddingInfo;

  landlord: string | null;

  totalPool: number;

  deckInfo: DeckInfo;

}

```

### 玩家模型

```typescript

interface Player {

  id: string;

  name: string;

  role: 'farmer' | 'landlord';

  isActive: boolean;

  handValue: number;

  handCount: number;

  roundCount: number;

  bidAmount: number;

  entryFee: number;

  finalScore: number | null;

  hasDrawnThisRound: boolean;

  hasActedThisRound: boolean;

  currentRoundCards: string[];

}

```

### 卡牌模型

```typescript

interface Card {

  id: string;

  type: 'value' | 'bomb' | 'system_value' | 'system_bomb';

  originalValue: number;

  currentValue: number;

  isFlipped: boolean;

  originalOwner: string | null;

}

```

### 竞拍信息模型

```typescript

interface BiddingInfo {

  currentBid: number;

  currentBidder: string | null;

  biddingRound: number;

  biddingTurnCount: number;

}

```

### 牌库信息模型

```typescript

interface DeckInfo {

  totalCards: number;

  remainingValue: number;

  flippedCards: number;

  remainingValueCards: number;

  remainingValueTotal: number;

}

```

## 错误码说明

| 错误码 | 说明 |

|--------|------|

| 400 | 请求参数错误 |

| 404 | 资源不存在 |

| 500 | 服务器内部错误 |

### 业务错误信息

| 错误信息 | 说明 |

|----------|------|

| "当前不在竞拍阶段" | 游戏状态不允许竞拍 |

| "不是当前竞拍玩家" | 不是轮到该玩家竞拍 |

| "出价必须高于当前最高价" | 竞拍金额不符合规则 |

| "当前不在游戏阶段" | 游戏状态不允许抽牌/翻牌 |

| "当前不在抽牌阶段" | 回合阶段不允许抽牌 |

| "当前不在翻牌阶段" | 回合阶段不允许翻牌 |

| "玩家状态错误" | 玩家不存在或状态异常 |

| "本轮已抽过牌" | 玩家在当前回合已经抽过牌 |

| "可抽牌数量不足" | 牌库中可用牌数不足 |

| "至少需要翻开一张牌" | 翻牌操作至少需要选择一张牌 |

| "只能翻开本轮抽到的牌" | 只能翻开当前回合抽到的牌 |

| "玩家未抽牌或无抽牌记录" | 玩家没有抽牌记录 |

## 使用示例

### 完整游戏流程示例

```javascript

// 1. 初始化游戏

fetch('/api/init-game', {

  method:'POST',

  headers:{'Content-Type':'application/json'},

  body: JSON.stringify({

    playerNames: ['Alice','Bob','Charlie','David']

  })

});


// 2. 竞拍阶段

fetch('/api/place-bid', {

  method:'POST',

  headers:{'Content-Type':'application/json'},

  body: JSON.stringify({

    playerId:'alice-uuid',

    amount:30

  })

});


// 3. 抽牌

fetch('/api/draw-cards', {

  method:'POST',

  headers:{'Content-Type':'application/json'},

  body: JSON.stringify({

    playerId:'alice-uuid'

  })

});


// 4. 翻牌

fetch('/api/flip-cards', {

  method:'POST',

  headers:{'Content-Type':'application/json'},

  body: JSON.stringify({

    playerId:'alice-uuid',

    cardIds: ['card-1','card-2']

  })

});


// 5. Socket.IO 监听

constsocket=io();

socket.on('gameStateUpdate', (state) => {

  updateUI(state);

});

```
