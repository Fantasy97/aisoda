# SBOM IDE 项目讲解与扩展开发指南

## 📋 项目概述

**SBOM IDE (ASW S-G2 Sales IDE)** 是一个基于 Vue 3 的太阳能逆变器销售配置工具，采用类似 VS Code 的 IDE 界面设计。该项目主要用于：

- 产品配置和展示（ASW S-G2 系列逆变器）
- 销售工具集成（收益计算、AI 导购、3D 模型等）
- 项目方案管理和预览
- PDF 导出功能

## 🛠️ 技术栈

### 核心技术
- **Vue 3** (v3.4.21) - 使用 Composition API (`<script setup>`)
- **Vite** (v5.1.4) - 构建工具和开发服务器
- **Tailwind CSS** (v3.4.1) - 实用优先的 CSS 框架
- **Font Awesome 6** - 图标库（通过 CDN）

### 项目配置
- **路径别名**: `@` 指向 `./src` 目录
- **开发端口**: 5173
- **构建输出**: `dist` 目录，包含 sourcemap

## 🏗️ 核心架构

### 1. 主组件：SBOMIde.vue

这是整个应用的核心组件，实现了 IDE 风格的多窗口管理系统。

#### 主要功能模块：

**A. 状态管理（使用 Vue 3 Composition API）**
```javascript
// 核心状态
const projectItems = ref([])        // 项目项列表
const openWindowIds = ref([])       // 打开的窗口ID列表
const gridCols = ref([50, 50])      // 网格列宽比例
const gridRows = ref([50, 50])      // 网格行高比例
const activeSidebarTab = ref('builder')  // 侧边栏活动标签
```

**B. 窗口管理系统**
- 最多支持 4 个窗口同时打开
- 动态网格布局（1-4 窗口自适应）
- 窗口拖拽排序
- 窗口大小调整（通过 gutter）

**C. 侧边栏系统**
- **组件库（Explorer）**: 可拖拽的组件列表
  - ASW S-G2 系列产品
  - 销售工具（计算器、AI助手、3D查看器等）
- **项目目录（Builder）**: 已添加的项目项管理

**D. AI 命令栏**
- 顶部 AI 输入框
- 下拉聊天面板
- 可打开完整版 AI 助手窗口

**E. 预览和导出**
- 预览模态框
- PDF 导出功能（模拟）

### 2. 窗口组件系统

每个窗口组件都遵循统一的接口：

```vue
<script setup>
defineProps({
  item: {
    type: Object,
    default: () => ({})
  }
})
</script>
```

**组件映射表**：
```javascript
const componentMap = {
  'product': ProductWindow,
  'calculator': CalculatorWindow,
  'ai-assistant': AiAssistantWindow,
  '3d-viewer': Viewer3DWindow,
  'product-params': ProductParamsWindow
}
```

### 3. 数据流

```
组件库 (Explorer)
    ↓ (拖拽/点击)
项目目录 (Builder)
    ↓ (打开窗口)
工作台 (Canvas) → 窗口组件渲染
    ↓ (预览)
预览模态框 → PDF 导出
```

## 🎯 核心功能详解

### 1. 拖拽系统

**三种拖拽场景**：

1. **从组件库拖到项目目录**
   - 创建新的项目项
   - 自动生成唯一 `instanceId`

2. **从项目目录拖到工作台**
   - 打开已存在的项目项窗口

3. **工作台内窗口拖拽**
   - 交换窗口位置
   - 重新排列布局

### 2. 网格布局系统

使用 CSS Grid 实现灵活的窗口布局：

```javascript
// 1个窗口：全屏
gridTemplateColumns: '1fr'
gridTemplateRows: '1fr'

// 2个窗口：左右分屏
gridTemplateColumns: '50% 4px 50%'

// 3个窗口：左1个，右2个（上下）
gridTemplateColumns: '50% 4px 50%'
gridTemplateRows: '50% 4px 50%'

// 4个窗口：2x2 网格
gridTemplateColumns: '50% 4px 50%'
gridTemplateRows: '50% 4px 50%'
```

### 3. 窗口调整大小

通过 `gutter`（分隔条）实现窗口大小调整：
- 垂直 gutter：调整左右窗口宽度
- 水平 gutter：调整上下窗口高度

### 6. 添加状态持久化

使用 localStorage 保存项目状态：

```javascript
// 保存
function saveProject() {
  localStorage.setItem('sbom-project', JSON.stringify({
    items: projectItems.value,
    openWindows: openWindowIds.value
  }))
}

// 加载
function loadProject() {
  const saved = localStorage.getItem('sbom-project')
  if (saved) {
    const data = JSON.parse(saved)
    projectItems.value = data.items || []
    openWindowIds.value = data.openWindows || []
  }
}

// 在 onMounted 中调用
onMounted(() => {
  loadProject()
})

// 在项目变更时自动保存
watch([projectItems, openWindowIds], () => {
  saveProject()
}, { deep: true })
```

## 📝 开发建议

### 1. 代码组织
- 将大型组件拆分为更小的子组件
- 提取可复用的逻辑到 composables（Vue 3 的 hooks）
- 使用 TypeScript 增强类型安全（可选）

### 2. 性能优化
- 使用 `v-memo` 优化列表渲染
- 懒加载窗口组件
- 虚拟滚动处理长列表

### 3. 测试
- 为关键功能添加单元测试
- 使用 Vue Test Utils 测试组件

### 4. 错误处理
- 添加全局错误处理
- 使用 try-catch 包装异步操作
