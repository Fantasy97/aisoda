## 设计特点

### 1. 视觉风格
- **渐变背景**: 紫色渐变 (#667eea → #764ba2)，与现有cursor-changer风格一致
- **毛玻璃效果**: 卡片使用backdrop-filter实现半透明毛玻璃效果
- **动态背景**: 点状图案背景，缓慢移动动画
- **浮动动画**: 桌宠图标有上下浮动动画

### 2. 卡片设计
每个功能卡片包含：
- **大图标**: 64px emoji图标，悬停时放大旋转
- **标题**: 28px粗体，悬停时变为主题色
- **描述**: 16px灰色文字，说明功能用途
- **标签**: 渐变背景的小标签，显示功能类型
- **悬停效果**: 
  - 上浮10px并轻微放大
  - 阴影加深
  - 边框高亮
  - 3D倾斜效果（鼠标跟随）

### 3. 响应式布局
- **桌面端**: 4列网格布局（每列最小280px）
- **平板端**: 2列布局（每列最小240px）
- **手机端**: 单列布局

### 4. 动画效果
- **页面加载**: 卡片依次从下方淡入
- **悬停交互**: 平滑的变换和阴影效果
- **点击反馈**: 按下时的缩放反馈
- **加载状态**: 跳转前的脉冲动画

### 5. 交互功能
- **点击跳转**: 点击卡片跳转到对应功能页面
- **键盘支持**: 支持Tab导航和Enter/Space激活
- **页面检测**: 跳转前检查目标页面是否存在
- **加载提示**: 跳转时显示加载动画

## 颜色方案

```css
主背景渐变: #667eea → #764ba2
卡片背景: rgba(255, 255, 255, 0.95)
文字颜色: #333 (标题), #666 (描述)
主题色: #667eea
标签背景: 渐变 (#667eea → #764ba2)
```

## 字体设置

```css
字体族: -apple-system, BlinkMacSystemFont, "Segoe UI", "Helvetica Neue", Arial, "Microsoft YaHei"
标题: 48px (桌面) / 36px (平板) / 28px (手机)
卡片标题: 28px (桌面) / 24px (平板) / 22px (手机)
描述文字: 16px
标签: 12px
```

## 间距规范

```css
容器最大宽度: 1200px
卡片间距: 30px (桌面) / 20px (移动端)
卡片内边距: 40px 30px (桌面) / 30px 20px (平板) / 25px 20px (手机)
头部底部间距: 60px (桌面) / 40px (移动端)
```

## 使用说明

1. 打开 `desktop-pet-demo.html` 查看主页面
2. 点击任意功能卡片跳转到对应功能页面
3. 如果功能页面尚未创建，会显示提示信息
4. 支持键盘导航（Tab键切换，Enter/Space激活）
