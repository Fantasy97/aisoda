# 系统模块功能对照表

## 📋 文档说明

本文档整合了超级BOM系统、Agent智能交互系统、智能BOM决策系统的所有模块与功能,以表格形式呈现,便于快速查阅和理解。

---

## 一、超级BOM系统

### 1.1 知识治理模块

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **BOM知识提取组件** | 文档型数据库提取 | 从MongoDB、Elasticsearch等文档型数据库中提取BOM相关数据(设计文档、工艺文档、质量记录) |
| | 关系型数据库提取 | 从Oracle、MySQL、SQL Server等关系型数据库中提取BOM主数据、物料信息、供应商信息 |
| | 网络爬虫引擎 | 通过Scrapy、Selenium等爬虫框架采集外部BOM数据(供应商信息、行业标准、市场价格) |
| **BOM数据处理组件** | 数据清洗 | 对原始BOM数据进行去重、格式标准化、空值处理、异常值检测、错误修正 |
| | 数据筛选 | 根据业务规则筛选有效BOM数据,过滤无效、过期、废弃数据,进行质量分级 |
| | 数据脱敏 | 对敏感信息(成本、供应商报价、技术机密)进行加密、匿名化、掩码处理 |

### 1.2 数据生成模块

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **超级BOM数据生成模块** | 数据模型组装 | 将清洗后的数据融合成统一的超级BOM数据模型(结构+成本+供应链+工艺+质量) |
| | 数据增强 | 自动补全缺失关联、计算派生字段(总成本、层级深度)、添加元数据标签 |
| | 版本管理 | 为每个BOM生成版本号、记录变更历史、建立版本间diff关系 |

### 1.3 多态存储模块

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **存储引擎组件** | 关系型数据库 | 存储结构化BOM主数据(MySQL/PostgreSQL/Oracle),支持事务、复杂SQL查询 |
| | Meta存储(文档数据库) | 存储半结构化数据(MongoDB/Couchbase),灵活Schema,设计文档、工艺文档存储 |
| | Neo4j图存储 | 存储BOM层级关系、物料关联网络、供应链图谱,支持图算法(最短路径、社区发现) |
| | 时序存储 | 存储BOM变更历史、成本价格趋势、性能监控数据(InfluxDB/TimescaleDB) |
| **预处理组件** | 数据检验 | Schema校验、业务规则校验、完整性校验、外键约束检查 |
| | Embedding库型 | 将BOM数据转换为向量表示(文本Embedding、图Embedding),支持语义搜索 |
| | 问题存储 | 存储质量问题、设计缺陷、成本优化建议(MongoDB灵活Schema) |
| **检索引擎组件** | 审排序模型 | 对检索结果智能排序(相关性+质量+业务权重),Learning to Rank |
| | 混合检索 | 结合关键词检索、语义检索、图检索、结构化查询(RRF融合算法) |
| | 数据调度 | 多存储引擎间智能调度(读写调度、负载均衡、一致性保证) |

### 1.4 智能分析模块

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **分析引擎** | BOM结构分析 | 层级深度分析、物料分布分析、复杂度评估 |
| | 成本分析 | 成本分解(物料成本/人工成本/制造费用)、成本趋势分析、成本对比 |
| | 供应链分析 | 供应商风险识别、单一供应商检测、供应链路径分析 |

### 1.5 强化设计模块

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **AI推荐引擎** | 物料推荐 | 基于ML模型推荐物料,业务规则过滤,性价比排序 |
| | BOM模板推荐 | 基于相似度检索推荐BOM模板,聚类分析,代表性选择 |
| **设计优化算法** | 成本优化 | 识别高成本物料、查找替代方案、生成优化建议(降本8-15%) |
| | 供应链优化 | 识别单一供应商风险、推荐备用供应商、供应商分散化 |

### 1.6 系统集成模块

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **重排元模型(映射引擎)** | 映射关系管理 | 建立超级BOM与PLM/ERP/MySQL的字段映射关系(YAML配置) |
| | 数据转换 | 字段级转换(truncate/round/lookup),业务规则转换 |
| **数据调度(集成调度器)** | 全量同步 | 批量推送所有活动BOM到外部系统(批量100条) |
| | 增量同步 | 基于时间戳的增量数据同步,定期更新 |
| | 实时同步(CDC) | 基于Kafka监听MySQL binlog,实时推送变更事件 |
| | 错误处理与重试 | 指数退避重试机制(最多3次)、失败补偿机制 |
| **结果返回(统一接口)** | RESTful API | 提供标准化API接口(GET/POST/PUT/DELETE),JSON格式响应 |
| | Webhook通知 | 异步推送变更通知到订阅者,支持重试 |

### 1.7 BOM服务管理组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **服务能力** | 数据质量监控 | 监控BOM数据的完整性(缺失率<5%)、准确性(格式错误率)、一致性(跨系统对账)、时效性(延迟<4h) |
| | 查询服务 | 提供多维度BOM查询接口(精确查询、模糊查询、多维查询、关联查询),支持缓存、分页 |
| | 订阅服务 | 支持用户订阅BOM数据变更通知(BOM变更、物料价格、供应商变更),多渠道推送(邮件/消息队列/Webhook) |
| | 统计服务 | 提供BOM数据统计分析功能(数量统计、使用频率、成本趋势、供应商分布),生成报表(日报/周报/月报) |
| | 血缘追踪 | 追踪BOM数据的来源(源系统标识、采集时间)、变更历史(完整链路)、影响分析(向上/向下/横向)、责任追溯 |

## 二、Agent智能交互系统

### 2.1 用户交互组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **前端入口** | 安全效验 | 用户身份认证(JWT/SSO)、权限校验(RBAC)、输入验证(XSS/SQL注入防护)、频率限制(令牌桶算法) |
| | 需求输入 | 接收用户自然语言输入、格式规范化、上下文信息收集、多模态输入支持(文本/语音/图片转文本) |
| | 总结输出 | 结果格式化(Markdown/HTML/JSON)、可视化生成(图表/表格)、可解释性增强(推理过程/置信度)、多渠道输出 |

### 2.2 管理员Agent组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **核心调度中枢** | 意图识别 | 理解用户意图(BERT分类)、识别任务类型(查询/分析/优化/执行)、提取关键实体(NER)和参数、意图消歧 |
| | 任务分发 | 根据意图选择专家Agent、任务分解与并行调度、任务优先级管理、失败重试与降级 |
| | 结果分析 | 聚合多Agent返回结果、一致性检查(相似度计算)、冲突消解(投票机制)、质量评估(完整性+置信度+覆盖率) |
| | 结果反馈 | 格式转换、生成可操作建议、更新上下文、触发后续动作(通知/工单) |

### 2.3 专家Agent组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **性能协焊Agent** | 物料性能分析 | 物料技术参数分析、性能指标评估 |
| | 替代方案推荐 | 替代物料匹配、技术可行性评分(>0.7采纳)、风险评估 |
| **ODM Agent** | 供应商管理 | 供应商绩效分析、供应链风险识别(单一供应商、集中度) |
| | 采购成本优化 | 批量采购机会识别、价格谈判空间分析、潜在节省计算 |
| **安规Agent** | 法规合规检查 | RoHS/REACH/CE等认证检查、有害物质检测 |
| | 认证评估 | 认证有效期验证、认证状态查询、合规风险预警 |

### 2.4 MCP组件(Model Context Protocol)

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **工具调用能力** | 搜索引擎 | 多源数据检索(技术数据库/供应商数据库/认证数据库/知识库)、语义搜索、结果排序 |
| | 沙盒计算 | 安全代码执行、复杂计算(BOM成本递归汇总)、数据分析(线性规划) |
| | 其他工具 | 数据库查询工具、API调用工具、文件处理工具(PDF/Excel解析、报告生成) |

### 2.5 存储层

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **配置管理** | 策略配置 | 系统配置管理(Agent权重/超时时间)、意图识别配置(模板/NER规则)、任务分发策略、结果聚合策略 |
| **数据存储** | 超级BOM多态存储 | 与超级BOM系统集成,提供数据持久化(BOM主数据/设计文档/关系图/历史变更) |

## 三、智能BOM决策系统

### 3.1 预处理组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **系统入口** | 用户需求输入 | 接收多种形式用户需求(BOM优化/新品设计/替代方案/合规检查)、需求格式规范化、初步需求理解 |
| | 需求特征提取 | 提取关键特征(产品特征/约束条件/优化目标/合规要求)、结构化需求信息、生成特征向量(Sentence-BERT) |
| | 安全校验 | 需求合法性校验(参数范围/逻辑一致性)、权限验证(角色/数据权限)、资源可用性检查(Agent/存储/并发)、风险评估(异常/恶意) |

### 3.2 智能体群策略模型组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **领域专家Agent** | 性能规格Agent | 技术规格分析、技术参数匹配验证(电压/功率)、性能指标评估(>0.7阈值)、技术可行性验证、BOM方案组装 |
| | 安规Agent | 法规合规性校验(RoHS/REACH/CE)、认证要求验证、安全风险识别、合规性报告生成(合规率计算) |
| | 其他Agent | 成本Agent/供应链Agent/质量Agent/工艺Agent(可扩展) |

### 3.3 奖励模型组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **强化学习评估** | 成本Agent | 评估BOM成本表现,计算奖励分数(成本控制50%+成本结构30%+价格稳定性20%) |
| | 其他奖励Agent | 性能奖励Agent(性能达成度)、质量奖励Agent(质量等级/可靠性)、供应链奖励Agent(供应商稳定性/交期)、合规奖励Agent(认证通过率) |

### 3.4 参考模型组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **历史经验借鉴** | 相似BOM检索 | 检索历史相似BOM,提供设计参考(向量检索+综合相似度=规格40%+成本20%+场景10%+向量30%),TOP K推荐 |
| | 相似需求检索 | 检索历史相似需求及解决方案,提供决策参考(语义检索+方案性能+经验教训) |

### 3.5 数据生成组件

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **训练数据生成** | 应用差异策略 | 对比多Agent方案差异(成本/物料数量/性能/合规),提取优劣特征,与参考案例对比,生成改进建议 |
| | 多规则评估 | 基于多维规则评估BOM质量(成本30%+性能25%+合规20%+供应链15%+质量10%),生成综合评分,评分分级(优秀/良好/合格/不合格) |

### 3.6 数据层

| 组件名 | 模块名 | 功能描述 |
|-------|--------|---------|
| **数据持久化** | 超级BOM多态存储模块 | 与超级BOM系统集成,提供数据持久化(MySQL/MongoDB/Neo4j/InfluxDB) |
| **训练数据管理** | 超级BOM数据生成模块 | 生成高质量训练数据(多Agent方案+奖励评分+参考案例+多规则评估),数据质量检查,数据标注(最优方案/问题点),反馈到存储模块用于Agent训练 |
