# 组件开发快速参考

## 🚀 快速开始

### 1. 创建组件文件
```bash
# 在 src/frontend/src/components/ 目录下创建
RequirementDiscussionWindow.vue
```

### 2. 复制模板
使用 `ComponentTemplate.vue` 作为起点，或参考现有组件（如 `ProductWindow.vue`）

### 3. 注册组件（3处修改）

#### ① 导入组件（SBOMIde.vue 第804行附近）
```javascript
import RequirementDiscussionWindow from '../../components/RequirementDiscussionWindow.vue'
```

#### ② 注册到组件映射（SBOMIde.vue 第1005行附近）
```javascript
const componentMap = {
  // ... 现有映射
  'requirement-discussion': RequirementDiscussionWindow,
}
```

#### ③ 添加图标（SBOMIde.vue 第988行附近）
```javascript
if (item.type === 'requirement-discussion') iconClass = 'fa-solid fa-comments text-blue-500'
```

## 📋 组件 Props

```javascript
// 所有组件必须接收 item prop
defineProps({
  item: {
    type: Object,
    default: () => ({})
  }
})

// item 结构
{
  instanceId: 'inst-xxx',        // 实例ID
  type: 'product',               // 组件类型
  title: '组件标题',              // 显示标题
  originalId: 'requirement-discussion' // 原始ID
}
```
