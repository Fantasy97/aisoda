## 📊 数据流图

```
用户操作
    │
    ├─► 拖拽组件库项目
    │       │
    │       ▼
    │   创建 projectItem
    │       │
    │       ▼
    │   添加到 projectItems[]
    │
    ├─► 点击项目目录项
    │       │
    │       ▼
    │   添加到 openWindowIds[]
    │       │
    │       ▼
    │   渲染窗口组件
    │
    ├─► 拖拽窗口
    │       │
    │       ▼
    │   更新 openWindowIds 顺序
    │       │
    │       ▼
    │   重新计算布局
    │
    └─► 预览/导出
            │
            ▼
        生成预览内容
```

## 🔧 技术债务清单

### 高优先级
1. **SBOMIde.vue 重构** - 1600+ 行代码，难以维护
2. **状态管理缺失** - 需要 Pinia 管理全局状态
3. **类型安全缺失** - 需要 TypeScript
4. **错误处理缺失** - 需要全局错误边界

### 中优先级
5. **测试覆盖缺失** - 需要添加单元测试
6. **性能优化** - 需要代码分割和懒加载
7. **文档完善** - 需要 API 文档和组件文档

### 低优先级
8. **主题系统** - 支持多主题切换
9. **国际化** - 支持多语言
10. **PWA** - 支持离线使用

## 🚀 快速开始改进

### 第一步：重构核心组件
```bash
# 创建 composables 目录
mkdir -p src/composables
mkdir -p src/components/layout
```

### 第二步：添加状态管理
```bash
npm install pinia
```

### 第三步：添加路由
```bash
npm install vue-router@4
```

### 第四步：添加类型支持
```bash
npm install -D typescript @vitejs/plugin-vue-jsx
```
